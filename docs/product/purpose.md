# Purpose — QueueLess

## What it is

QueueLess is a lightweight **digital queue management** system. It replaces uncertain physical waiting with a ticket you can watch on your phone.

## Problem

People waste time standing in line without knowing their place or wait. Staff manage order with fragile, non-shared tools.

## Who it serves

- **Customers / visitors** — join, monitor, get called.
- **Operators / staff** — run the live queue at the service point.
- **Small venues** — campus services, clinics desks, small retail/food counters, similar one-line flows.

## Intended experience

**Customer:** scan or open link → join → get number → see position, now-serving, ETA → updates → served or leave.

**Operator:** open dashboard → see queue → call next → skip/remove when needed → basic stats → reset/end when the session is done.

## Product goals

1. Simplicity — minutes to understand, not a training manual.
2. Fast interaction — join and call-next feel instant.
3. Correct shared queue state under concurrent joins and serves.
4. Low operational complexity for small teams.
5. Privacy-conscious by default (anonymous tickets).
6. Small-business / campus usable without heavy setup.
7. Reliable enough to become a portfolio-quality project later — while keeping the MVP small.
